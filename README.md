# Pulsetrain Website

A responsive, modern website for Pulsetrain, a leading provider of EV Battery Management Systems (BMS) and multi-level inverter technology.

## Features

- **Responsive Design:** Optimized for desktop and mobile viewports.
- **Modern Tech Stack:** Built with Next.js 15, React 19, Tailwind CSS 4, and Lucide React.
- **Component-Based Architecture:** Clean, reusable components for Hero, Technology, Applications, Partners, and Team sections.
- **Performance Optimized:** Uses Next.js App Router and optimized styling with Tailwind CSS.

## Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Build

To build the project for production:

```bash
npm run build
```
